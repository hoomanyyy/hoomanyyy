## Forkwise

<a href="https://github.com/hoomanyyy/Forkwise-AI"><img src="https://raw.githubusercontent.com/hoomanyyy/Forkwise-AI/main/frontend/public/site/app-workspace.webp" alt="Forkwise" width="100%"></a>

**[Forkwise](https://forkwiseai.com)** is an open-source AI engineer. Describe an app, a site or a fix, and it plans the work, writes the code in an isolated computer, runs and tests it, and reviews its own work before it reports back.

- **Agent and API**: FastAPI, an agent loop with 30 tools and 26 expert skills, MCP connectors, checkpoints and a public streaming API
- **Sandbox**: a Docker computer for every chat, with a browser and live previews
- **Clients**: a React web app, a desktop editor built on Electron and Monaco, and an Android app built with React Native
- **Models**: works with any OpenAI-compatible provider, users' own API keys, or local models

[Source code](https://github.com/hoomanyyy/Forkwise-AI) · [Try it](https://forkwiseai.com) · [Download](https://github.com/hoomanyyy/forkwise-releases/releases/tag/current) · [Docs](https://forkwiseai.com/docs)
